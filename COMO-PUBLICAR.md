# Como publicar

## GitHub

1. Extraia este ZIP.
2. Crie um repositório no GitHub.
3. Envie o conteúdo da pasta avicola-dias-site.
4. Para trabalhar localmente: npm ci, depois npm run dev.
5. Para gerar a versão de produção: npm run build.

## Hostinger

1. Abra o Gerenciador de Arquivos da Hostinger.
2. Entre em public_html.
3. Envie o arquivo avicola-dias-hostinger.zip.
4. Extraia o ZIP diretamente em public_html.
5. Confirme que index.html e a pasta assets ficaram diretamente em public_html.

A Hostinger não precisa de Node.js para este pacote estático.
